# Моделирование и стабилизация маятника на тележке с помощью PID-регулятора и PSO

## 📌 Описание проекта

Проект посвящён моделированию динамики системы «тележка–маятник» и автоматическому подбору коэффициентов PID-регулятора с использованием алгоритма роя частиц (Particle Swarm Optimization, PSO).

Цель проекта — подобрать параметры регулятора, которые обеспечивают уменьшение углового отклонения маятника от вертикального положения при различных начальных углах.

Вся реализация представлена в Jupyter Notebook `MIITU_KADETOV_II(1).ipynb`.

## 🎯 Основные задачи

- Математическое моделирование динамики маятника на тележке.
- Реализация PID-регулятора для управления системой.
- Ограничение управляющей силы для моделирования физических ограничений.
- Оптимизация коэффициентов PID-регулятора с помощью PSO.
- Оценка качества управления при различных начальных условиях.
- Визуализация сходимости алгоритма оптимизации и динамики системы.

## ⚙️ Математическая модель

Система включает тележку массой \(M\) и маятник массой \(m\), длина которого равна \(l\).

В модели используются следующие параметры:

| Параметр | Значение | Описание |
|---|---:|---|
| `M` | 0.5 | Масса тележки |
| `m` | 0.2 | Масса маятника |
| `l` | 0.3 | Длина маятника |
| `g` | 9.81 | Ускорение свободного падения |
| `F_MAX` | 15.0 | Максимальный модуль управляющей силы |

Состояние системы описывается переменными:

- \(x\) — положение тележки;
- \(v\) — скорость тележки;
- \(\theta\) — угол отклонения маятника;
- \(\omega\) — угловая скорость маятника;
- `integral` — интеграл угловой ошибки, используемый PID-регулятором.

Для численного моделирования применяется функция `solve_ivp` из библиотеки SciPy с методом `RK45`.

## 🎛 PID-регулятор

Управляющая сила определяется выражением:

\[
F = -(K_p\theta + K_i I + K_d\omega),
\]

где:

- \(K_p\) — пропорциональный коэффициент;
- \(K_i\) — интегральный коэффициент;
- \(K_d\) — дифференциальный коэффициент;
- \(I\) — накопленный интеграл угловой ошибки.

Управляющая сила ограничивается диапазоном:

\[
-15 \leq F \leq 15.
\]

Такое ограничение позволяет учитывать допустимый диапазон воздействия на систему.

## 🐝 Оптимизация с помощью PSO

Для автоматического подбора коэффициентов PID-регулятора используется алгоритм роя частиц (PSO).

Каждая частица представляет собой набор из трёх параметров:

\[
\mathbf{p} = [K_p, K_i, K_d].
\]

Алгоритм обновляет положения и скорости частиц, учитывая их собственные лучшие решения и лучшие решения соседей. Используется кольцевая топология: соседями частицы являются она сама и две соседние частицы.

### Параметры алгоритма

| Параметр | Значение |
|---|---:|
| Количество частиц | 30 |
| Количество итераций | 60 |
| Коэффициент инерции `w` | 0.7 |
| Когнитивный коэффициент `c1` | 1.5 |
| Социальный коэффициент `c2` | 1.5 |
| Диапазон \(K_p\) | [0, 100] |
| Диапазон \(K_i\) | [0, 50] |
| Диапазон \(K_d\) | [0, 50] |

### Функция качества

Для оценки каждого набора коэффициентов выполняется моделирование системы в течение 10 секунд для четырёх начальных углов:

- \(-\pi/4\);
- \(-\pi/8\);
- \(\pi/8\);
- \(\pi/4\).

Функция качества учитывает три составляющие:

1. Среднеквадратичную ошибку угла маятника (RMS).
2. Абсолютное конечное смещение тележки.
3. Штраф за выход угла за пределы \(\pm\pi/2\).

Для каждого начального угла используется функционал:

\[
J = 100\theta_{\mathrm{RMS}}
+ 10|x_{\mathrm{final}}|
+ P,
\]

где \(P\) — штраф, равный 1000 при превышении указанного углового порога и 0 в противном случае.

Итоговая функция качества представляет собой сумму значений для всех четырёх начальных условий. Алгоритм стремится минимизировать её.

## 📊 Результаты работы

После выполнения ноутбука выводятся:

- Оптимальные значения коэффициентов \(K_p\), \(K_i\) и \(K_d\).
- Лучшее найденное значение функции качества.
- График сходимости PSO, показывающий изменение лучшего значения функционала по итерациям.
- Графики динамики системы для каждого из четырёх начальных углов.

Для каждого начального условия строятся четыре графика:

- положение тележки \(x(t)\);
- скорость тележки \(v(t)\);
- угол маятника \(\theta(t)\);
- угловая скорость маятника \(\omega(t)\).

Это позволяет оценить поведение системы во времени и сравнить результаты управления при различных начальных отклонениях.

Обратите внимание: конкретные оптимальные коэффициенты и итоговое значение функции качества зависят от фактического выполнения алгоритма и его случайной инициализации.
